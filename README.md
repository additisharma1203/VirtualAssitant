# 🤖 Virtual Assistant

A simple AI-powered Virtual Assistant built using **JavaScript** and the **Google Gemini API**. This project demonstrates the basic implementation of a conversational assistant with speech input and text-based responses.

The assistant can listen to the user's voice, convert speech into text, send the query to the Gemini API, and display the AI-generated response on the user interface as a chat conversation.

> **Note:** This is a beginner/foundation-level project created for learning purposes. It does not include advanced NLP models, intent recognition, application automation, or task execution.

---

## 🚀 Features

* 🎤 Speech-to-Text using browser Speech Recognition
* 🤖 AI-generated responses using Google Gemini API
* 💬 Chat interface displaying both user and assistant messages
* ⌨️ Supports text-based conversation
* ⚡ Fast response generation
* 📱 Simple and responsive UI
* 🔄 Real-time conversation updates

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/virtual-assistant.git
```

### 2. Navigate into the project

```bash
cd virtual-assistant
```

### 3. Add your Gemini API Key

Replace the placeholder API key in your JavaScript file.

```javascript
const API_KEY = "YOUR_GEMINI_API_KEY";
```

### 4. Run the project

Simply open

```
index.html
```

in your browser.

Or use **VS Code Live Server** for a better development experience.

## 📖 How It Works

1. User clicks the microphone button.
2. Browser converts speech into text.
3. The text is sent to the Google Gemini API.
4. Gemini generates an AI response.
5. The response is displayed in the chat interface.
6. (Optional) The response is spoken aloud using Speech Synthesis.
